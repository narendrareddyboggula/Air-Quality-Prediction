Project title: Air Quality Index Prediction by Using Machine and Deep Learning (TK174464 - New Dev)
Actual title: Air Quality prediction

dataset link: https://www.kaggle.com/datasets/rohanrao/air-quality-data-in-india?utm_source=chatgpt.com


This is a classification project. 
in here we are going to predict the quality of air, whether air quality is good or Satisfactory otherwise it's poor using air quality data.


classifications (Air quality):
	1. Poor
	2. Satisfactory
	3. Good


Algorithms: 
	1) Logistic regression
	2) MLP classifier
	3) Random forest classifier
	4) Decision tree classifier
	5) adaboost classifier
	6) XGBoost classifier
